# Apple 风格界面改版

设计依据：[apple-design-skill](https://github.com/dickwu/apple-design-skill)，本机安装名 `apple-design-skill`。项目是 React Web / PWA，将 HIG 的可读性、布局、导航与材质原则映射到语义化 HTML 和 CSS，不冒充原生 UIKit 或真正的 Liquid Glass 渲染。

## 改版前的审查

- **可读性**：旧版移动端辅助文字低至 7–10px，低于所读 `accessibility.md › Vision` 的移动端最小建议 11pt；改为正文 17px、辅助 13px，最小数据标记 12px，以 rem 支持浏览器字号设置。
- **触控**：收藏、加餐与步进按钮原先多为 22–29px。依据 `buttons.md › Best practices` 的 44×44pt 命中区建议，提高到至少 44×44 CSS px。
- **层级**：移除无业务含义的英文眉题与重复品牌装饰，保留主任务、餐品和个人记录。依据 `branding.md › Best practices`，品牌应让位于内容。
- **材质**：依据 `liquid-glass.md › Where the material belongs`，透明与模糊只用于悬浮导航 / 工具栏，内容卡片保持实色。
- **外观**：依据 `dark-mode.md › Best practices` 跟随系统明暗设置，并支持减少动态效果、减少透明度与高对比度偏好。
- **弹窗**：依据 `sheets.md › Best practices`，同时只打开一张原生 dialog；子流程暂时关闭父面板，返回时恢复，保持原有数据与选择。

## 设计计划

产品：麦游记。面向想快速点餐、也愿意尝鲜的个人用户。核心任务是从真实餐品中找到下一餐，辨识点保留为餐品主视觉与「味觉护照」。没有通用宣传大数字，也不引入苹果标志。

六个语义色角色分别为背景、内容面、主文字、辅助文字、操作色、状态色，均定义明暗变体。操作色使用麦游记自己的暖橙，只强调主按钮和当前导航。白色内容卡片、系统字体与熟悉的导航负责承载操作；大幅真实餐品和个人护照负责表达趣味。相较原版，移除手账邮戳式首页装饰，让食物本身成为主角。

字体：系统字体栈；大标题 34px、节标题 22px、正文 17px、次级 15px、说明 13px、最小数据标记 12px，均以 rem 表达。没有外部字体下载。

紧凑宽度：

```text
[麦游记                    设置 / 餐袋]
[日期                               ]
[发现                               ]
[个人化餐品主视觉 + 开启探索          ]
[点餐 / 盲盒 / 钱包 / 活动             ]
[餐品列表 / 灵感 / 活动               ]
[     发现  点餐  灵感  钱包  护照      ]
```

常规宽度：

```text
[侧栏导航] [轻量工具栏                         ]
[        ] [大标题                            ]
[        ] [主视觉与探索入口                    ]
[        ] [餐品网格 / 内容分组                  ]
```

动效：只在开启盲盒 / 转盘时短暂出现；普通导航仅做轻量淡入。减少动画偏好下去除非必要过渡。保留现有官方核价、交易确认、演示标识和私人数据边界。

## 验证

改版完成后记录：手机 / 桌面布局、系统深色模式、键盘操作、面板返回和模拟核价流程。Web 无法等同原生 Dynamic Type，使用浏览器 200% 字体缩放检查布局。对比度按实际十六进制颜色计算，不从截图估算。

## 实测结果（2026-11-02）

| 角色     | 浅色      | 深色      | 对比度（对应内容面） |
| -------- | --------- | --------- | -------------------- |
| 背景     | `#f5f5f7` | `#000000` | 非文字               |
| 内容面   | `#ffffff` | `#1c1c1e` | 非文字               |
| 主文字   | `#1d1d1f` | `#f5f5f7` | 16.83:1 / 15.63:1    |
| 辅助文字 | `#636369` | `#aeaeb2` | 5.97:1 / 7.69:1      |
| 操作色   | `#b64413` | `#ffb088` | 5.49:1 / 9.57:1      |
| 状态色   | `#257044` | `#8bd5a0` | 仅作带文字状态标记   |

暖色餐品主视觉中的辅助文字为 5.07:1。悬浮栏使用不透明的主文字色，避免底层照片造成小字号标签对比不足。

- 手机 390×844 的浅色和深色均完成视觉检查，主图、字号和五个导航入口保持一致。
- 200% 根字号（34px）检查：首页文字正常换行，触发单列重排，文档宽度维持 390px，无横向滚动。
- 商城进入商品详情：DOM 中只存在一个 `dialog[open]`。关闭详情后恢复商城，不丢失上一步状态。
- 餐品 → 餐袋 → 演示核价 → 订单预览 → 取消确认：已完成，返回餐袋后「打包带走」选择仍保留。
- 自动化业务检查：48 项测试通过，TypeScript 和 Vite 生产构建通过。未操作真实账户权益或支付。

保留的区别是「真实餐品主视觉 + 个人味觉护照」。移除的装饰是重复英文眉题、邮戳式首页图案和桌面右侧重复推荐栏；每个主要入口继续可达。

补充检查：360px 窄屏的文档宽度为 360px，可见文字最小计算字号约 12px；没有宽或高低于 28px 的可见按钮。减少透明度偏好下悬浮导航的 `backdrop-filter` 为 `none`，高对比度辅助文字切换为 `#414147`。子面板返回时恢复父面板的滚动位置与键盘焦点。
