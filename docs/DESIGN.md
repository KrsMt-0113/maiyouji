# 设计笔记

产品名是「麦游记」，把一餐当作一段不费力的小旅行。目标是愿意尝新、喜欢收集日常、偶尔有选择困难的个人用户。既能处理完整业务，也留出“没有必要，但很好玩”的空间。

## 五个口袋

发现页像一张当天的旅行封面；点餐页是地图；灵感实验室帮人迈出随机的一小步；钱包负责真实权益；护照保存自己的生活。五个入口在手机底部始终可达，桌面改为左侧导航。

视觉采用奶油纸张底色、橘红操作色、鼠尾草绿和低饱和配色。原创 SVG 汉堡旅行插画与护照、纸票、虚线印章构成视觉语言。没有复制官方 App 界面，也不暗示官方产品身份。

## 趣味不制造业务幻觉

盲盒与转盘仅从当前菜单里发现餐品，不含奖品或付费抽取机制。报价与详情仍由用户打开后查看。个人印章是手写日记，探索徽章按个人记录点亮，不把它们画成官方任务奖励。

官方积分抽奖单独放在钱包，并完整展示积分或次数消耗。时光胶囊只在本机按日期揭晓文案，没有加密承诺。

## 手机交互

- 360px 起的布局、底部导航和安全区域。
- 原生 dialog 的弹窗、浏览器焦点限制与 Escape 关闭。
- 大多数主要操作使用底部按钮；输入表单字体避免手机浏览器自动缩放。
- 请求中、无结果、业务失败、离线均有明确状态。
- 护照卡片可导出 PNG；生成过程不拉取远程图片，不携带账户隐私。
- 支持减少动画偏好；不做无限自动滚动、自动抽奖或自动播放。

## 暂时的边界

这是私人单账户应用：MCP Token 对应单一官方账户；同浏览器保存个人手账。没有多人账户隔离、团队拼单服务、推送消息或公网部署。手机 PWA 是响应式 Web 应用，不是原生 iOS / Android 安装包。
