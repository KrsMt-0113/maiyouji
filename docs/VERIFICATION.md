# 验证记录

验证日期：2026-10-29（北京时间）。

## 自动化

执行 `npm run check`：

- Vitest：金额分/元转换、公开数据解析、套餐轮次、默认配料、去除配料、同 code 不同特调 key、无限制哨兵、取餐方式与业务编码、随机预算与关键词边界、抽奖服务端决策、链接过滤。
- 交易测试：预览不写入、60 秒失效、会话绑定、单次使用、并发重复提交、核价变化、消耗变化、写请求超时不自动重试、商城规格检查。
- HTTP 集成：跨源请求拦截、会话 token、应用访问口令、只读路由不能调用写工具、非法订单号、完整演示点餐与取消链路。
- TypeScript 类型检查及 Vite 生产构建。

真实 MCP SDK 发现的 Schema 另外在每次真实工具调用前校验输入。

## 真实只读联调

通过应用本身的 HTTP API 连接官方服务，不使用前端静态模拟假装真实接入。已验证 11 项只读工具；结果记录在 `live-verification.json`，只保留工具名、成功标记、耗时与 trace ID，不包含账户余额、券码、订单、地址或凭据。

本地重跑：先以 `PORT=4318 npm run dev:codex` 启动已授权的真实实例，再执行：

```bash
python3 scripts/smoke-live.py http://127.0.0.1:4318
```

脚本在真实模式不成立时会拒绝把结果标为 live；不会执行任何写工具。固定示例门店只用于已知公开数据的开发验证。
